# AHMIX — الموقع الشخصي لأحمد عبدالفتاح

موقع شخصي تعريفي مبني بالكامل بـ **HTML5 + CSS3 + JavaScript** خالص — بدون أي قوالب أو أطر عمل.

> **AHMIX — More Than Just AI** 🚀

## 📂 هيكل المشروع

```
AHMIX-Website/
├── index.html          ← هيكل الموقع كاملًا (عربي RTL)
├── style.css           ← نظام التصميم + كل الحركات والتجاوب
├── script.js           ← كل التفاعلات (وحدات منظمة ومعلّقة)
└── assets/
    ├── img/            ← الصور والشعار واللقطات (مُحسّنة للويب)
    ├── video/          ← الفيديوهات (مضغوطة H.264 + faststart)
    └── fonts/          ← خطوط Cairo و Orbitron محلية (تعمل بدون إنترنت)
```

## ✨ المميزات

- **شاشة افتتاح سينمائية** بشعار AHMIX ومدارات متحركة
- **جسيمات تفاعلية** في الخلفية تستجيب لحركة المؤشر (Canvas)
- **مؤشر مخصص** متوهج + **أزرار مغناطيسية**
- **ميلان ثلاثي الأبعاد** (3D Tilt) للصور والبطاقات
- **كاتب أدوار متغير** (Typing Effect) في الواجهة
- **ظهور ذكي للمحتوى** عند التمرير (IntersectionObserver)
- **معرض تمرير تلقائي** بصفين متعاكسين يتوقفان عند المرور
- **قسم شهادات موثّقة** بإطارات تفاعلية وختم دوّار + نافذة عرض وروابط تحقق رسمية
- **عمل مميز سينمائي:** فيديو يعزف تلقائيًا عند الوصول إليه مع أزرار أوامر متزامنة مع مشاهده وزر صوت
- **نافذة عرض** (Lightbox) للفيديوهات والصور
- **زر واتساب ثابت** + بطاقات تواصل + نسخ البريد بضغطة
- متجاوب بالكامل (موبايل / تابلت / كمبيوتر) + دعم `prefers-reduced-motion`

## 🚀 التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
# من داخل مجلد المشروع
python -m http.server 8080
# ثم افتح http://localhost:8080
```

## ✏️ كيف تعدّل المحتوى؟

| ما تريد تعديله | المكان |
|---|---|
| النصوص والأقسام | `index.html` — كل قسم موسوم بتعليق واضح |
| الألوان والخطوط | `style.css` — متغيرات `:root` في الأعلى |
| سرعة/نوع الحركات | `style.css` — كل قسم له كتلة معلّقة |
| الأدوار المتغيرة | `script.js` → وحدة `TypeRotator` → مصفوفة `WORDS` |
| صور المعرض | `script.js` → وحدة `Gallery` → مصفوفة `IMAGES` |
| روابط التواصل والواتساب | `index.html` (ابحث عن `wa.me`) |
